What it does

Three layers, one canonical surface.

Existing platforms stay the content layer — YouTube, Twitch, Bluesky. ManaMap is the layer that organizes them.

01 · Like IMDb

The directory

Structured search across every active MTG creator. Filter by format, color, content type, audience style, region, follower size. The first place fans look — and the first place a sponsor looks before signing a deal.

→ Discovery + recommendations
02 · Like LinkedIn

The identity layer

One canonical profile per creator. Auto-syncs YouTube, Twitch, Bluesky, Moxfield. Bio, formats, decks, schedule, past appearances. Replaces the Linktree-plus-spreadsheet-plus-screenshot media kit with something real.

→ Profile + media kit
03 · Like Bandsintown

The events layer

Conventions, RCQs, LGS nights, signings. Creators mark appearances; fans track events; stores discover creators to book. Local scenes get real surface area — Seattle first, then everywhere.

→ Events + store pages + booking
02 · Identity

One profile. Every platform.

A canonical page at manamap.gg/c/[handle] — auto-aggregating your YouTube uploads, Twitch status, Bluesky posts, Moxfield decks, and upcoming appearances. Built to be your highest-signal link in bio.

Principles

A tool, not a feed.

01

Directory, not feed.

No timeline. No algorithmic ranking by recency. No posting surface. Users come back when they have a job.

02

Structured data first.

Every creator, event, and store has typed metadata. The directory is defensible because the schema is.

03

Existing platforms are the content layer.

YouTube hosts the videos. Twitch hosts the streams. ManaMap deep-links — never replicates.

04

Fans free forever.

Discovery never gets paywalled. Monetization sits on the tools creators, stores, and brands want.

05

SEO is a first-class surface.

Every creator, tag, event, and region is a server-rendered page. Long-tail search is half the moat.

06

Niche-first.

MTG only, for as long as it takes. Pokémon, Lorcana, FaB come later — never as a launch shortcut.

Where we are

Shipping in phases.

No big launch. Onboard quietly, build the directory under-the-radar, then announce when the data is the moat.
